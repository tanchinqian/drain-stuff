# Reference node firmware — untested on hardware

Arduino ESP32 + MCCI Arduino-LMIC/SX1276 sketch implementing switched measurement, float flags, normal/event sampling, a persisted 24-bit counter, payload encoding and deep sleep after transmit/receive completes. Configure the approved regional plan in LMIC, check exact board pins, and provide an ignored `secrets.h` with `APP_EUI[8]`, `DEV_EUI[8]`, `APP_KEY[16]` and an explicit `DRAIN_RADIO_APPROVED` definition. No radio band or credentials are supplied. Radio API reference: [MCCI OTAA example](https://github.com/mcci-catena/arduino-lmic/blob/master/examples/ttn-otaa/ttn-otaa.ino).

This sketch has **not been compiled against an Arduino toolchain, flashed, RF-tested or bench-tested**. The host-only encoder check does not change that. DIO1 uses GPIO33 in addition to the schematic's DIO0 GPIO26. `GPIO25 HIGH` drives the NPN to switch on the PMOS rail. Echo divider and boost are mandatory; check trigger logic threshold. Pulse distance assumes 343 m/s; temperature compensation requires an independently measured ambient sensor. The 29°C field is a **placeholder** to replace before any device use, not a measured temperature. Optional soil probe sampling is not implemented in v1.

Important limits: the reference sketch restarts OTAA after each deep sleep; session/DevNonce persistence and join-failure backoff need a board/library-specific implementation before field use. The power budget does not include repeated joining. Timing/rising thresholds, ADC divider calibration and stuck detection are provisional. Counter persistence survives ordinary reboot, but a factory reset requires a new commissioned EUI to avoid replay collisions. No field readiness is claimed.

`g++ -std=c++11 firmware/node/host_test.cpp -o <temporary-output>` runs assertions against the exact JS decoder test vector. The firmware encoder and canonical decoder agree on the 12 bytes; test source is committed. This is the only compiled firmware-related code claimed here.
