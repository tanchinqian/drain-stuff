They are explanatory wiring/placement drawings, not PCB manufacturing files. All dimensions/values are proposed inputs pending bench review.

## Pin-level netlist

Reference uses a bare ESP32 module and separate SX1276-class 3.3 V radio. An integrated board requires a revised pin map. Check boot straps and module pin availability before layout.

| Net | Connection | Proposed component / constraint |
|---|---|---|
| Battery | Protected LiFePO4 pack → fused input | 3.2 V nominal, 4000 mAh assumption; protection and charger selected for exact chemistry |
| 3V3 | Battery → 3.3 V buck/boost → ESP32/radio | Load/transient capability to be measured; local decoupling 100 nF plus bulk capacitance |
| 5V | Battery → 5 V boost → PMOS source | Switched ultrasonic rail; converter quiescent current must be budgeted |
| Sensor power | PMOS drain → ultrasonic VCC | Gate 100 kΩ to 5 V source; NPN pulls gate low, emitter GND, collector gate; GPIO25 → 10 kΩ base; 100 kΩ base pulldown. PMOS current/Rds and gate limits to be selected. **No direct 5 V gate connection to ESP32.** |
| Trigger | GPIO17 → ultrasonic trigger | Verify that purchased module accepts a 3.3 V high; use a level translator if required |
| Echo | Ultrasonic echo → 12 kΩ → GPIO16; GPIO16 → 18 kΩ → GND | 5 V echo becomes approximately 3.0 V. Verify timing, tolerance and actual module output |
| Float | GPIO27 → float → GND | 10 kΩ pullup to 3.3 V; debounce in firmware; closed means water at crest |
| Moisture optional | GPIO34 ADC1 ← capacitive probe output | Supply 3.3 V; output must remain within ADC limits; calibrate, indicator only |
| Battery monitor | Battery → 330 kΩ → GPIO35 ADC1 → 100 kΩ → GND | 3.65 V becomes ~0.85 V; 100 nF ADC capacitor; divider included in assumed sleep budget |
| Radio SPI | GPIO18 SCK, 19 MISO, 23 MOSI, 5 NSS | GPIO5 is a boot strap; ensure radio does not pull an invalid boot level |
| Radio control | GPIO14 reset, GPIO26 DIO0, GPIO33 DIO1 | Reference LMIC sketch uses both interrupts; exact breakout must be checked |
| RF | Radio ANT → matched connector → regional antenna | Band, antenna, power and local approval **unverified** |
| Ground | Battery, regulators, MCU, sensor, float, radio | Common return; isolate/strain-relieve external cables |

Before fabrication: electrical review, surge/ESD protection and fuse selection, regulator stability, ADC calibration, sensor pulse levels, PMOS off leakage, RF layout/antenna compliance, enclosure test and field safety approval.
