# 3D scene assets

Round 9 uses original procedural geometry and textures. No photographs, downloaded models, logos, brand assets or third-party texture packs are included.

| Asset | Source | Licence / provenance |
|---|---|---|
| Soil, mulch, sand, gravel, concrete, asphalt, paving, grass and filter-fabric albedo/normal maps | `app/src/three/sceneMaterials.ts`, generated locally from deterministic noise and periodic variation | Original procedural project assets; no third-party licence |
| Section face hatching | `app/src/three/SectionCaps.tsx`, generated canvas pattern | Original procedural project asset |
| Shared three-colour built-context atlas | `contextAtlas` in `app/src/three/sceneMaterials.ts`, shared by terrace/roof/trim/props | Original procedural project asset |
| Terrace fronts, windows, doors, gutter/downpipe, kerb, foundations, road markings, lamp, utility pole and covers | `app/src/three/CatchmentContext.tsx`, boxes and instancing | Original procedural project geometry; illustrative context, not surveyed buildings |
| Tropical grasses, broadleaf clumps, mulch pieces, gravel and CAD drainage parts | `app/src/three/physicsGeometry.ts`, instanced primitives and merged closed solids | Original procedural project geometry |
| Confirmed obstruction debris | `app/src/three/FaultDeposits.tsx`, deterministic instanced pieces | Original procedural project geometry; restriction cue, not a sediment-transport calculation |
| Overcast sky gradient, fog and rain-driven mist | `app/src/three/StormAtmosphere.tsx` | Original procedural project asset |
| Rain, impact rings, water shading, refraction, ripples and seepage | `app/src/three/WaterEffects.tsx` | Original procedural project geometry/shaders |
| Flow traces and cut plane | `app/src/three/FlowTrace.tsx`, `CutPlane.tsx` | Original procedural project geometry |

There are no external asset source URLs because all assets above are generated by these source files. The Three.js, React Three Fiber and Drei libraries remain existing code dependencies with their own licences in their package distributions; they are not new downloaded scene assets.
